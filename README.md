# Обществознание — подготовка к ОГЭ

Сайт для подготовки к ОГЭ по обществознанию (формат 2027: 20 заданий, 32 балла, «5» — от 28 баллов).
Кабинеты ученика и учителя, теория, банк заданий, карточки с понятиями и отслеживание цели.

## Что внутри

- **Главная** — приветствие, следующая тема, прогресс к цели, модули курса
- **Теория** — 6 модулей, 53 темы с краткими конспектами; отмеченные темы попадают в «Мою цель»
- **Задания** — 120 заданий (по 20 на модуль: 15 тестовых и 5 письменных), пробный вариант с таймером,
  марафон, работа над ошибками; тест проверяется автоматически, письменные — самооценка по критериям ФИПИ
- **Карточки** — 277 понятий по модулям: переворот, тест, список
- **Моя цель** — дни до экзамена, следующая тема, расписание тем, шкала оценок, пробники по месяцам
- **Кабинет учителя** — прогресс всех учеников и уведомления о решённых заданиях

## Технологии

React 19, TypeScript, Vite, Tailwind CSS 4, React Router. Сервер (по желанию) — Supabase.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:5173. Сборка для публикации: `npm run build` (готовый сайт — в папке `dist`).

## Публикация на GitHub Pages

Сайт собирается и публикуется сам при каждом изменении — за это отвечает файл `.github/workflows/deploy.yml`
(его копия лежит в `docs/deploy.yml`).

1. Загрузите проект в репозиторий на GitHub (ветка `main`).
2. Если в репозитории нет файла `.github/workflows/deploy.yml`: **Add file → Create new file**,
   имя `.github/workflows/deploy.yml`, вставьте содержимое `docs/deploy.yml`, **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь зелёной галочки (2–3 минуты).
5. Сайт будет доступен по адресу `https://<логин>.github.io/<имя-репозитория>/`.

Если репозиторий называется `<логин>.github.io`, замените в `deploy.yml` строку `VITE_BASE` на `VITE_BASE: /`.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/data/theory.ts` | темы модулей и конспекты |
| `src/data/tasks.ts` | банк заданий (`sourceId` — номер задания на «РЕШУ ОГЭ») |
| `src/data/flashcards.ts` | карточки с понятиями |
| `src/data/goalPlan.ts` | формат ОГЭ, шкала оценок, цель, типы письменной части |

## Источники

Задания — из открытого банка ФИПИ (через каталог «РЕШУ ОГЭ», soc-oge.sdamgia.ru), ответы и критерии оттуда же.

## Аккаунты: ученик и учитель

При регистрации выбирается роль:

- **Ученик** — теория, задания, карточки, цель. Каждое решённое задание отправляет уведомление учителю.
- **Учитель** — регистрируется с секретным кодом учителя. Видит всех учеников, их прогресс
  (темы, задания, точность по модулям, карточки, пробники) и ленту уведомлений о решениях
  (обновляется каждые 20 секунд, есть всплывающие и браузерные уведомления).

## Сервер: Supabase

Без настроек сайт работает в **демо-режиме**: все аккаунты хранятся в одном браузере
(код учителя в демо — `2027`). Чтобы ученики и учитель работали с разных устройств:

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (бесплатный тариф).
2. **SQL Editor → New query**: вставьте файл `supabase/schema.sql`, замените в нём
   `придумайте-код` на свой код учителя и нажмите **Run**.
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email**,
   чтобы ученики входили сразу после регистрации (иначе им придёт письмо со ссылкой).
4. **Project Settings → API**: скопируйте *Project URL* и ключ *anon public*.
   Создайте в папке сайта файл `.env` по образцу `.env.example` и вставьте их.
5. Для GitHub Pages добавьте эти же два значения в репозиторий: **Settings → Secrets and variables → Actions → New repository secret** (имена `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`). Для другого хостинга — `npm run build` и загрузите папку `dist`.
6. **Authentication → URL Configuration → Site URL**: укажите адрес опубликованного сайта.

Сменить код учителя позже: SQL Editor →
`update app_settings set value = 'новый-код' where key = 'teacher_code';`

Ключ *anon public* не секретный — он и должен быть на сайте. Защиту данных обеспечивают
правила доступа в `schema.sql`: ученик видит и меняет только своё, учитель только читает всех.

## Добавление заданий

Задания лежат в `src/data/tasks.ts`. Тестовое задание — `format: 'test'`, варианты в `options`,
номер верного варианта в `answer`. Письменное — `format: 'written'`, тип в `kind`, образец ответа
в `solution` и критерии в `criteria`. Картинки кладите в `src/assets/tasks/` и подключайте через `import`.
