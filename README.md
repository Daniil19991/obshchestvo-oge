# Обществознание — подготовка к ОГЭ

Образовательная платформа для подготовки к ОГЭ (и в перспективе ЕГЭ) по обществознанию.

## Разделы

- **Главная** — обзор прогресса и быстрый доступ к разделам
- **Теория** — 6 модулей ОГЭ, 18 уроков с возможностью отмечать пройденное
- **Задания** — 11 слотов по типам заданий ОГЭ (задания загружаются позже)
- **Личный кабинет** — профиль, портфолио, радарная диаграмма усвоения модулей
- **Моя цель** — целевой балл, дата экзамена, план и этапы подготовки

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:5173

## Сборка

```bash
npm run build
```

## Авторизация

При первом заходе откроется страница входа. Можно зарегистрироваться или войти по email и паролю. Прогресс каждого ученика хранится отдельно в браузере.

## Данные

Прогресс привязан к аккаунту и сохраняется в `localStorage`. Для продакшена рекомендуется подключить серверную авторизацию (Supabase, Firebase и т.д.).

## Добавление заданий

Задания добавляются в `src/data/practice.ts` — для каждого слота установите `tasksLoaded: true` и `tasksCount`, затем реализуйте UI решения в разделе «Задания».
